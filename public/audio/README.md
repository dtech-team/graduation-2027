# Hướng Dẫn Thêm Nhạc Nền (Background Music)

Bạn có thể tải bất kỳ bài nhạc nào bạn yêu thích (ví dụ: các bản nhạc Lofi, nhạc Tốt nghiệp, Piano, Synthwave...) và đặt vào thư mục này:

1. Đổi tên file nhạc của bạn thành: `bg-music.mp3`
2. Đặt vào thư mục: `public/audio/bg-music.mp3`
3. Trang web sẽ tự động nhận diện và phát bài nhạc của bạn với chất lượng cao nhất!

*(Nếu chưa có file `bg-music.mp3`, hệ thống sẽ tự động phát bản nhạc êm dịu demo online để trải nghiệm luôn trọn vẹn).*
